Your browser asks you to select the USB device. Nothing is written until you confirm the installation.

Before you connect

  1. Stop Watchling’s bridge: cd pc-bridge && npm run bridge:stop. Close serial monitors too.
  2. Connect Vocat by USB. If it is missing from the chooser, hold BOOT while reconnecting.
  3. Keep “Erase device” unchecked to preserve Settings and Bluetooth pairing. Erasing removes all device data.
  4. After installation, start a new Codex or Claude terminal session to reconnect the installed bridge.

The installer and firmware are served from this computer. It works offline after downloading the ZIP. Keep the terminal open; press Ctrl-C when finished.
